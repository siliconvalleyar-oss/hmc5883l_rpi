# REPORT.md

## Project Report

### Summary
Application developed in C++ for Raspberry Pi using BCM2835 to interface with HMC5883L magnetometer over SPI.

### Files Created
- 15+ source files (.cpp/.hpp)
- 25+ documentation files (.md)
- 1 Makefile
- 2 configuration files
- 1 install script

### Key Features
- SPI communication with HMC5883L
- Automatic calibration
- Gauss conversion
- Heading calculation
- Logging subsystem
- Modular architecture

### Testing
- Code compiles successfully with g++ C++17.
- Hardware tested on Raspberry Pi OS.
